# 首页任务入口与摄影流程导航

日期：2026-10-18。范围：前端入口、导航、能力卡片和流程说明；接口、已有页面 URL 与交接参数不变。

## 入口与顺序

首页提供四种开始方式：

| 当前任务 | 入口 | 现有去向 |
| --- | --- | --- |
| 准备出门拍摄 | 规划一次拍摄 | `/planning` |
| 拍完一批照片 | 导入照片并选片 | `/assets` |
| 已有目标照片 | 分析并优化照片 | `/analysis` |
| 继续之前的工作 | 继续最近任务 | 首页 `#recent-tasks`，再沿用任务原有详情链接 |

导航顺序为：工作台 → 拍摄规划 → 素材库 → 照片分析 → 修图 → 学习复盘 → 历史。
能力卡片与流程说明共用 `photography-workflow.ts` 定义的五阶段顺序；补齐修图入口，卡片与各阶段均可点击。

首页原来的固定“实时协作链路”替换为摄影工作流程，明确推荐顺序可跳过、学习反馈不必等待修图。移除首页静态技术状态卡，不将 mock 状态作为实时服务健康依据；分析任务页的真实 Post / Coach 进度展示继续使用原有逻辑。

原项目存在 `app/page.tsx` 与 `app/(main)/page.tsx` 两份同址首页，本次统一到主布局内的后者，工作台 URL 仍为 `/`。没有新建后端接口或修改 API 基地址。

## 照片与建议衔接

- 分析结果仍使用 `/retouch?media_id=...&job_id=...`，没有省略或改名。
- 真实模式仍从目标任务的 `retouch-advice` 接口读取建议，并从对应媒体的 `retouch-source` 读取原图，再通过现有 `photoai:import` 消息交接。
- 手动另选本地文件时不读取原照片或其建议，避免串图。
- “继续最近任务”只是滚动到现有最近任务区，不声称恢复未保存的编辑。各任务仍按原类型及参数进入分析、规划、素材或学习页面。
