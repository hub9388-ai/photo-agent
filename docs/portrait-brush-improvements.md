# 人物局部选区的笔刷改进

## 问题与修改

原来的“笔刷”会将三个以上轨迹点自动闭合填充，实际更像套索；沿手臂来回涂可能选中没有涂过的内部区域。宽度固定，也没有减选操作。

现已明确分为：

- **涂抹**：默认，只选择笔迹覆盖范围，不自动闭合。
- **圈选**：保留原来的轨迹闭合填充方式。
- **添加／擦除选区**：擦除只减掉遮罩，不擦掉原照片像素；擦除时红色轨迹表示待减选范围。
- **粗细**：可调，显示原图像素直径，画布显示随缩放匹配的范围圆圈；单击也能落笔。
- **撤销／重做选区**：按顺序重放每一笔的粗细、模式和加减操作，不把所有笔画合并成同一粗细。
- 鼠标离开画布会结束当前笔画，避免回来后拖出意外连线。图片工具运行期间不提交新的选区。

刷新后若界面没有本地选区，新一笔会先清除服务端遗留的隐藏遮罩，避免画面看不到的旧区域被追加。
旧客户端未传 `shape/operation` 时保留原来的圈选、添加语义。

## 透明缺口检查

截图显示的失败是候选图透明检查拒绝采用，不等于笔刷提交失败。此前检查候选整张图的透明度，可能把不会采用的选区外透明区域一起拒绝。

现在检查与最终合成一致的尺寸及选区：选区内任何有覆盖的像素出现透明缺口仍拒绝；选区外像素始终来自原图。未降低人物原图、选区确认和严格合成的保护要求。

这只是修正检查范围，**无法仅凭截图确认该次透明缺口具体位于哪里，也不保证人物生成效果自然**。本轮未付费重跑人物模型。

## 使用

1. 刷新页面，在原图会话点击“笔刷”，建议先点“清除”去掉旧选区。
2. 放大目标手臂，选择“涂抹”，调小粗细；多选的边缘用“擦除选区”修整。
3. 点击“完成”，确认蓝色覆盖范围后重新发送人物修改要求，再确认执行计划。
4. 不直接重试绑定旧遮罩的失败步骤；选区已经改变，旧计划会被版本／遮罩检查阻止。

顶部工具较多时可横向滚动。原图保留，生成仍需模型额度可用。可以先分别编辑一侧上臂，避免一次覆盖两侧和大块背景。
