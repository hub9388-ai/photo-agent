# 人像局部编辑最小修复（2026-10-18）

## 为什么需要改代码

把“不要先拆层、保持人物自然”等要求写进工作台对话，不会修改后端规则。此次在服务端增加可执行的防护，提示词只用于辅助解释。原问题和固定素材见 `portrait-edit-audit-2026-10-18.md`。

## 已实现

1. 自动拆层只允许显式配置 rembg 的模式；corner 及 auto 回退模式在读取画布、背景重建和模型调用前被拦截。没有自动安装、下载或切换人物分割模型，显式 rembg 也不意味着已经通过效果验收。
2. 中文“瘦、纤细、收腰”等及英文 slim/slender 等身形关键词命中时，对话不再交由 LLM 安排多步拆层；后端固定准备一次 replace_region，并要求用户确认。当前是有限词表，不声称覆盖全部自然语言意图；部分执行核对问句排除在身形执行路由外。
3. 身形编辑仅允许原始素材对应的、未变换的单一 base 图层；已拆层、已采用的候选或缩放旋转过的图层拒绝继续叠加。现有会话和原图均不删除、不自动切换。
4. 要求原图上存在有效局部选区，面积非空且小于半张图；半张阈值是保守的产品限制，不是分割质量指标。用户应使用笔刷圈选腰部/躯干并避开脸、手和背景，系统没有实现自动脸部检测。
5. 把选区 ID 和修订号固定在计划中，计划状态为待确认；点击“执行计划”才会提交图像任务。执行时再次检查原图、修订号和当前选区 ID，旧计划、换选区或绕过规划器的工具请求不能忽略这些要求。
6. 简化模式下，旧 background+subject 拆层文档的区域生成也会拒绝，避免继续消费旧的错误人物范围。
7. 身形编辑采用向选区内羽化的严格合成，最终 PNG 在选区外保留原图像素；含透明像素的模型候选不被写入/采用。生成式编辑在选区内部仍可能失真，不能承诺自然瘦身或完整人物保真。

主要修改：上游 `services/agent.py`、`tools/region.py`、`tools/layers.py`、`edits/mask.py`、`agent/graph.py`。统一保存在 `integrations/retouch-photoai.patch`，不直接分发上游整套源码。

## 用户操作

刷新修图页，选择原图或重新导入原图。在原图用“笔刷”圈出小范围腰部或躯干，发送“仅将选区内腰部轻微收窄，保留服装和其他部分”。核对选区后点击“执行计划”。该最后一步会调用图像模型并可能消耗额度，未在本轮代用户执行。

不要把开发改造要求输入修图聊天框；聊天框用于描述当前照片编辑目标。旧的坏候选仍可在历史里查看，但不应继续用于身形编辑。

本轮没有修复 Post→修图参数映射，也没有引入新分割模型；照片自然程度、衣物/肢体保真和复杂场景质量仍待后续单样本人工验收。
