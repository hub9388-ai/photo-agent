# 分析结果可读性改进（2026-10-18）

## 本轮目标

针对双猫案例，精简分析结果默认展示，修正方向矛盾，保留原始建议与导出内容。本轮没有实现摄影参数到 Pillow 的转换，也没有重新调用模型、创建修图任务或改变既有分析结果。

## 变化

- 后期建议与学习反馈改为可切换页签，单份内容使用整个结果区宽度，支持键盘操作。
- 摘要默认最多三行，长摘要可展开；主要问题使用清楚的列表，不再重复添加两套项目符号。
- 有结构化风格方向时沿用模型内容；缺少时不再把完整长回答重复塞进“风格方向”。摘要已展示的信息不会再重复生成同一分组。
- 原始 adjustments 保留为“调整建议”：默认显示前三项，其余可展开；单项过长时也可展开全文。构图、色温等文字建议不会因 XMP 有值而消失。
- XMP 以“参数／建议值／方向”表格展示。“摄影软件参考值，尚未转换”只统一说明一次，不在每行重复长段落。不添加已执行、已校准或等价等承诺。
- 根据正负值展示中性、明确的参数方向，例如 Shadows2012=-10 对应“压暗暗部”，Vibrance=-10 对应“降低自然饱和度”。这些是源建议的方向解释，不是执行入参换算。
- 数值不再被前端四舍五入到一位小数，例如 +0.25EV 原样保留。
- 原始模型全文和分析依据保留，全文默认折叠；Markdown 导出包含完整建议、参数、分析依据和原文。
