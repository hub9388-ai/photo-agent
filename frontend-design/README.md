# 前端页面设计文件

本目录包含摄影全栈多 Agent 协同应用的 Pencil 线框图设计文件。

## 文件清单

| 文件 | 页面 | 说明 |
|------|------|------|
| `dashboard.pen` | 工作台首页 | 上传入口、进行中的任务、最近结果、快捷统计 |
| `analyze.pen` | 分析页 | 核心功能页：上传预览、实时分析控制台、结果展示 |
| `assets.pen` | 素材库 | 项目导入、素材网格、筛选、Handoff 操作 |
| `plan.pen` | 拍摄规划 | 需求表单、方案生成、时间线展示 |
| `history.pen` | 历史记录 | 任务列表、搜索筛选、分页、重试操作 |

## 使用方法

1. 确保已在 VS Code 安装 **Pencil** 扩展 (`highagency.pencildev`)
2. 在 VS Code 左侧活动栏点击 **Pencil** 图标
3. 点击 **"Open File"** 选择本目录下的 `.pen` 文件
4. 在 Pencil 编辑器中查看和编辑线框图

## 设计规范

### 布局
- 画布尺寸：1440 × 900（桌面端标准分辨率）
- 内容区宽度：1392px（左右各 24px 边距）
- 顶部导航栏高度：56px

### 颜色体系
| 用途 | 色值 |
|------|------|
| 页面背景 | `#F8FAFC` |
| 卡片背景 | `#FFFFFF` |
| 主色调（文字/按钮） | `#0F172A` |
| 边框/分割线 | `#E2E8F0` |
| Post Agent 主题 | `#3B82F6`（蓝） |
| Coach Agent 主题 | `#22C55E`（绿） |
| 成功状态 | `#166534` |
| 警告状态 | `#92400E` |
| 失败状态 | `#DC2626` |

### 字体
- 主字体：Inter
- 标题：16-24px，font-weight 600-700
- 正文：13-14px，font-weight 400-500
- 辅助文字：12px，font-weight 400

### 圆角规范
- 大卡片：cornerRadius 12-16
- 按钮：cornerRadius 8-10
- 标签/徽章：cornerRadius 4-6

## 页面交互说明

### Dashboard（工作台）
- 点击上传区进入分析流程
- 进行中的任务卡片实时显示 SSE 进度
- 最近结果卡片点击跳转历史详情

### Analyze（分析页）
- 三栏布局：左（预览）、中（实时状态）、右（结果）
- Post/Coach Agent 独立进度条
- 实时输出流模拟 `agent.delta` 效果
- 结果区骨架屏 → 实际结果切换

### Assets（素材库）
- 网格/列表视图切换
- A/B/C/淘汰/重复 五级筛选
- 选中素材底部弹出 Handoff 操作栏
- 支持批量送去后期/学习

### Plan（拍摄规划）
- 左表单右结果的双栏布局
- 方案 A/B/C Tab 切换
- 时间线展示拍摄行程
- 导出 PDF / 生成风格预设 / 采用方案

### History（历史记录）
- 列表项展示任务摘要和状态
- 失败任务显示针对性重试按钮
- 支持搜索、类型筛选、状态筛选
